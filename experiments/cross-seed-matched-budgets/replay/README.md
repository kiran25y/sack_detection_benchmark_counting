# Reproduce the evaluation

Download [banks.tar](https://github.com/kiran25y/sack_detection_benchmark_counting/releases/download/sack-benchmark-v1/banks.tar) into the full_factorial directory without extracting the tar. From this directory run python -B verify_review.py using Python 3.10+, NumPy 1.22+ and SciPy. The script verifies the file identities and all of the reported comparisons, including the draft-to-final point audit.
