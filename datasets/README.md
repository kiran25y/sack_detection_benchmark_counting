# Datasets

| Prepared dataset | Contents | Target |
|---|---|---|
| [Visible-sack benchmark](visible-sacks/) | 116 native frames, 1,337 reviewed centers in ten recording groups | Filled sacks in the designated foreground operation |
| [Roboflow detection](roboflow-carried-sacks/) | 24,007 images and 16,400 boxes | Carried or handled sacks |
| [Reviewed totals](reviewed-totals/) | 300 image-linked counts | Whole-image visible sack count |

The totals refer to images already in the Roboflow export. Each dataset card links to its original image package or matching source archive.
